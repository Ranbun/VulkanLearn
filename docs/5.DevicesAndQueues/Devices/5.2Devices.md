## 逻辑设备

&ensp;&ensp;设备对象代表与物理设备的逻辑连接。每个设备公开多个队列族，每个队列族有一个或多个队列。队列族中的所有队列支持相同的操作。<br>
&ensp;&ensp;如前面的“物理设备”一节所述，`Vulkan`应用程序首先会查询系统中的所有物理设备。然后可以查询每个物理设备的功能，包括其队列和队列族属性。一旦确定了可接受的物理设备，应用程序将创建相应的逻辑设备。创建的逻辑设备随后成为与物理设备进行交互的主要接口。<br>
&ensp;&ensp;如何枚举系统中的物理设备并查询这些物理设备的队列族属性在上面的“物理设备枚举”部分中有描述。<br>
&ensp;&ensp;如果这些物理设备属于同一设备组，则可以从多个物理设备创建单个逻辑设备。设备组是一组支持相互访问内存并在所有物理设备上记录单个命令缓冲区的物理设备。通过调用`vkEnumeratePhysicalDeviceGroups`来枚举设备组，并通过`VkDeviceGroupDeviceCreateInfo`将物理设备传递给设备组中的子集，可以从设备组中的多个物理设备创建逻辑设备。为了使两个物理设备属于同一设备组，它们必须支持相同的扩展、功能和属性。

<p style="color: #707070" Size=10>
    <font color=red Size=4>Notes</font>:<br>
    &ensp;&ensp;在同一设备组中的物理设备必须非常相似，因为没有规定不同功能或属性之间的交互规则。它们必须对几乎所有不变的功能、属性、能力等返回相同的值，但可能在某些查询上有所不同，比如连接了不同的显示器或使用了不同的合成器。规范没有尝试枚举每个状态属于哪个类别，因为这样的列表很快就会过时。使用vkGetPhysicalDevice*函数可以查询物理设备的属性和功能信息。
 </p>
&ensp;&ensp;要获取系统中存在的设备组列表，调用以下函数：

```C++
// Provided by VK_VERSION_1_1
VkResult vkEnumeratePhysicalDeviceGroups(
    VkInstance                                  instance,   // a handle to a Vulkan instance
    uint32_t*                                   pPhysicalDeviceGroupCount, //一个指向整数的指针
    VkPhysicalDeviceGroupProperties*            pPhysicalDeviceGroupProperties //一个指向VkPhysicalDeviceGroupProperties结构数组的指针
);
```
