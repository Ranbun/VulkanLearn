### Present Wait 呈现等待

Present Wait（呈现等待）是一种用于同步呈现操作的机制。在某些情况下，呈现操作可能会在帧缓冲区不可用时等待可用的帧缓冲区。使用Present Wait机制，可以确保在进行呈现之前等待帧缓冲区的有效性。这有助于避免产生图像撕裂等视觉问题。在Vulkan中，Present Wait可以通过信号量或者栅栏来实现。

当应用程序使用 Vulkan API 进行呈现时，它通常会将图像排队进行呈现，然后继续执行其他工作。这可能导致多个图像在呈现队列中排队等待呈现。如果应用程序没有限制排队的图像数量，可能会导致一些图像在排队等待呈现时积累，从而增加响应用户输入或渲染环境变化的延迟。

为了解决这个问题，VK_KHR_present_wait扩展提供了一种机制，允许应用程序在调用vkQueuePresentKHR时通知呈现引擎，它计划等待特定的呈现过程。为此，应用程序可以传递一个VkPresentIdKHR结构，其中包含一个表示当前呈现操作的标识符（presentId）。

然后，应用程序可以使用vkWaitForPresentKHR调用并传递相同的presentId，以阻塞其执行，直到呈现引擎通知该特定的呈现操作已完成。这允许应用程序控制排队的图像数量，使得在呈现之前只有有限数量的图像排队等待，从而减少响应延迟。

通过使用VK_KHR_present_wait扩展，应用程序可以更精确地控制呈现过程，并优化性能和用户体验。
