# 逻辑设备

- 逻辑设备可以有多个，彼此之间独立。
- 是你的应用程序与这块物理设备交互的软件接口或运行时对象。你可以将它想象成你与 GPU 签署的一份“合同”。

也可以认为他是一套接口，这个接口是调用的物理设备提供的功能与特性，但是我们可以使用哪些特性是在创建逻辑设备的时候选择启用的，即使某个特性物理设备是支持的，但是逻辑设备在创建的时候没有选择启用，那么在后续的功能中你还是不能使用他。

- 还有一件事是在创建逻辑设备的时候请求设备扩展。

| 元素 | 设计理念 |
|:--------  | :------ |
| 队列族配置 | 强制开发者精确声明需要哪些工作队列（图形、计算、传输）以及各自的优先级。 目的： 驱动可以提前为这些工作负载做好最优化的调度和资源分配。|
| 特性启用   | 强制开发者明确开启需要的硬件特性（如几何着色、镶嵌等）。 目的： 驱动无需检查或加载未使用的功能，从而减少驱动程序的开销，提升启动速度 |
| 扩展请求   | 必须显式列出所有要使用的非核心功能（如交换链）。 目的： 确保应用只在支持所需功能的硬件上运行，并在运行时避免不必要的兼容性检查。 |
