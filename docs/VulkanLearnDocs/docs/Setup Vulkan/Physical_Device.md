# 物理设备

## 查询物理设备

- 这只是通过Vulkan 实例来简单列出当前系统有的物理设备。
- 选择物理设备 (Check)： 您是在“查询”硬件的能力上限。您在问：“这块 GPU 到底能做什么？”
- 与之对应的: 创建逻辑设备 (Enable)： 是在“声明”您的程序将会使用什么。在告诉驱动：“在我这个程序中，我只需要这些功能。”


## 选择物理设备

- `vkGetPhysicalDeviceFeatures`

- 获取这个设备的所有特性之后，因为你知道你想要什么，你想要这个显卡做什么，你只需要判断这个能不能做就可以了，能做就用它，不能做就不用它。

### 物理设备筛选策略（Filtering）

理设备选择器（Selector）。这并非单一的 API 调用，而是开发者编写的一套启发式算法，用于在多个候选设备中找出最适合的一个。

筛选过程通常涉及遍历所有可用的 VkPhysicalDevice 句柄，并基于三大支柱对它们进行“评分”：==扩展支持、特性支持、队列族能力。==
