# VKInstance

- Vulkan的实例是开始的第一步，我们首先要做的就是创建一个实例，他代表是个什么概念呢？ 很难说，它更多表vulkan, 它定义了一个Vulkan环境， 后续的操作都是基于这个环境来进行的.
- Vulkan Instance有点类似于会话的概念，在这个会话的过程中，我才可以做操作.
- 在你能做任何与 Vulkan 相关的事情之前（比如检查有什么 GPU、创建窗口表面、创建设备等），你必须首先创建一个 VkInstance.

## 主要职责

- 加载Vulkan驱动(Vulkan 加载器)
- 加载全局扩展
- 加载验证层
- 查询(枚举)物理设备

##  实例扩展

- 简单说, 它是用来处理全局任务与系统相关的，但是与实际硬件无关的任务。
